# Executive Operator Redacted Example

A public, redacted example of a chief-of-staff style agent with an operating exoskeleton.

This example contains no real principals, tokens, private workspace IDs, customer data, or recipient allowlists. It demonstrates shape only:

- direct-mention-only workspace behavior
- authority and recipient policy overlays
- agent-owned connections
- unattended monitor state semantics
- action receipts and verification contracts

Use a private overlay repo for real identities, secrets, workspaces, groups, and domains.
