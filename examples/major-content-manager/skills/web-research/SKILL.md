# Web Research

Search the web for information and produce well-sourced findings.

## Process

1. Formulate 2-3 search queries that approach the topic from different angles
2. Fetch and read the most relevant results
3. Cross-reference claims across multiple sources
4. Present findings with source URLs

## Output Format

- Lead with the key finding or answer
- Support with 2-3 bullet points of detail
- Include source URLs at the end
- Flag confidence level (high/medium/low) if sources conflict
